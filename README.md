# Atelier Tiara

Generatore di tiare stampabili in 3D con scritta personalizzata. Gira tutto nel browser:
anteprima 3D, controllo di stampabilità e download degli STL, senza server e anche offline.

**Apri l'app:** https://mirketto1812engineer.github.io/atelier-tiara/

## Cosa fa
- Due versioni: **autoportante** (si stampa in piedi senza supporti) o **decorata** (più ghirigori, con supporti ad albero generati dall'app).
- Scritta con accenti in sei caratteri, fascia a molla che sta su da sola, dentini antiscivolo.
- Tre livelli di dettaglio: Principiante, Intermedio, Esperto.
- Download: zip con STL, progetto PrusaSlicer già impostato per **Prusa MK4S ugello 0,4**, fascia di prova per la calzata.
- Installabile sul telefono come app (Android: "Installa app"; iPhone: Condividi > "Aggiungi alla schermata Home").

## Aggiornare il sito
Carica i file nuovi in questo repository (Add file > Upload files): dopo un minuto il sito è aggiornato.
